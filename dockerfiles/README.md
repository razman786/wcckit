This directory contains the Docker build files and helper scripts for WCCKIT
profiling images.

The main user guide has been moved to the repository root README so it is shown
by GitHub on the project landing page:

```text
../README.md
```

Directory layout:

```text
dockerfiles/
  base/ubuntu-24.04.4/          Ubuntu 24.04 base profiling image
  profiling/bcc/                BCC/eBPF profiler image
  bin/                          Host-side install and run helpers
```
