# opti_disk

`opti_disk/` is a WCCKIT subset for disk speed, efficiency, NVMe, fio, and CPU/system-setting experiments. It is not part of the normal pipeline profiler workflow and is not run when using the Grafana viewer/collector wrappers.

Use it only for controlled storage characterisation where the target device is known and disposable or backed up.

Read [Safety](safety.md) before running any command in this area.
